# Citizenship RF Trainer 🇷🇺

Тренажёр по **истории России** и **основам законодательства РФ** для экзамена
с целью приобретения гражданства Российской Федерации. Полное соответствие
спецификации КИМ ФИПИ 2026.

## ✨ Возможности

- **36 заданий** — 18 по истории России (1–18) + 18 по законодательству (19–36)
- **40 первичных баллов**, порог сдачи — **28** (история ≥ 12, право ≥ 12)
- **4 варианта** заданий (A/B/C/D) с разными формулировками
- **3 режима**: 🎓 Тренировка (мгновенная проверка), 📝 Экзамен (без подсказок), 🔁 Ошибки (разбор)
- **Таймер на 90 минут** с предупреждением за 5 и 1 минуту
- **Двуязычный интерфейс** RU / EN
- **Тёмная и светлая тема**
- Фильтр заданий: все / только история / только законодательство
- Развёрнутые ответы (задания 11, 18, 33) с эталонами и самопроверкой
- Экспорт результатов в `.txt`, печать, копирование реквизитов
- **Один файл `index.html`** — работает офлайн, без сервера, без CDN, без зависимостей

## 🧩 Структура
Часть	Задания	Баллы
История России	1–18	20
Основы законодательства РФ	19–36	20
Итого	36	40
Задания 1–10, 12–17, 19–21, 23–32, 34–36 — краткий ответ, 1 балл

Задание 22 — краткий ответ, 2 балла

Задания 11, 18, 33 — развёрнутый ответ, по 2 балла

⚖️ Нормативная база
Конституция РФ, ст. 1–16

ГК РФ (сделки, собственность, обязательства)

ТК РФ (трудовой договор, приём на работу)

СК РФ (условия брака, режим имущества)

ФЗ от 28.04.2023 № 138-ФЗ «О гражданстве РФ»

ФЗ от 18.07.2007 № 109-ФЗ (миграционный учёт)

ФЗ от 15.08.1996 № 114-ФЗ (въезд/выезд)
